# Музыкальная библиотека

Информационная система для хранения, управления и анализа личной коллекции музыкальных треков.

## Описание проекта

Разработана клиент-серверная информационная система "Музыкальная библиотека", предназначенная для централизованного хранения, структурированного управления и анализа музыкальных треков и их метаданных.

Система не работает с аудиофайлами напрямую, а хранит только описательную информацию о треках.

## Основные возможности

- Хранение информации о музыкальных треках (название, исполнитель, жанр, bpm, длительность, дата создания)
- Поддержка категорий через справочник жанров и персонализированные коллекции
- Возможность добавлять, редактировать и удалять треки
- Поиск и фильтрация треков по различным критериям
- Управление профилем пользователя
- Аудит всех операций с фиксацией действий
- Разграничение прав доступа (пользователь/администратор)
- Веб-интерфейс на русском языке

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Установите и настройте PostgreSQL базу данных с именем `music_library`

3. Выполните скрипты для создания схемы и процедур:
```bash
psql -d music_library -f db_schema.sql
psql -d music_library -f stored_procedures.sql
psql -d music_library -f triggers.sql
```

4. Запустите Flask приложение:
```bash
python app.py
```

5. Откройте в браузере: http://localhost:5000

## Требования к системе

- Python 3.7+
- PostgreSQL 9.6+
- Flask 2.3+
- psycopg2-binary

## Архитектура

- **Клиент-серверная архитектура** с использованием модели сервера базы данных
- **Серверная часть** реализована на Python с использованием Flask
- **База данных** PostgreSQL с хранимыми процедурами на PL/pgSQL
- **Клиентская часть** реализована на HTML/CSS/JavaScript
- Все запросы к БД выполняются через хранимые процедуры
- Поддержка аудита операций и разграничения прав доступа
